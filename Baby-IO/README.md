Baby_IO

Baby_IO is an electronics and computer science project developed in 2025.
The system uses multiple sensors to detect whether a baby is awake or sleeping by analyzing sound, movement, and temperature.

The goal of the project is to monitor the baby's state and provide basic information to caregivers using simple hardware and sensor data.

Technologies / Components

Sound sensor

Motion sensor

Temperature sensor

Microcontroller-based system
