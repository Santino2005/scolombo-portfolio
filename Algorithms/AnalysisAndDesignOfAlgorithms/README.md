Algorithm Analysis and Design

Repository containing implementations of algorithms developed as part of the Algorithm Analysis and Design and Data Structures and Algorithms coursework.

This project includes algorithm implementations that range from fundamental concepts to more advanced problem-solving techniques, covering topics such as sorting algorithms, algorithmic complexity analysis, and core data structure principles.

Development

This project is configured with Gradle as the build tool. You can open it directly in your preferred IDE by selecting this folder and importing it as a Gradle project.

Your first implementation will be the Sorters.

Compile & Test

Your IDE should be ready to compile the project without additional configuration. Always manage the configuration through Gradle (build.gradle) and refresh the project in your IDE instead of modifying settings directly within the IDE.

To compile the project and run the tests from the terminal:

./gradlew clean test

Example tests are available in the test scope at Tests.

Commit & Push

Remember to regularly capture your progress through meaningful commits and push your changes to the remote repository.

The Continuous Integration (CI) pipeline on TeamCity will run automatically whenever changes are pushed to the repository.
