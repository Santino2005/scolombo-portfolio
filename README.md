## 🇪🇸 Proyectos Destacados

### ⚡ [UberClocked](./UberClocked) – PC Building & E-Commerce
- **Web:** [https://uberclocked.vercel.app](https://uberclocked.vercel.app)
- **Problema & Solución:** Evita incompatibilidades de hardware al armar PCs con un configurador en tiempo real (sockets/fuentes), catálogo (+200 productos) y pagos con Mercado Pago.
- **Stack:** Java 21, Spring Boot, React 19, TypeScript, Tailwind, PostgreSQL.

### 🏢 [GenoPass PRO](./genoPass) – Control de Accesos & QR
- **Web:** [https://geno-insights-challenge.vercel.app](https://geno-insights-challenge.vercel.app)
- **Problema & Solución:** Reemplaza planillas en papel y datos volátiles por una plataforma cloud con fotos webcam, credenciales QR dinámicas y reportes Excel.
- **Stack:** Java 21, Spring Boot 4, React 19, Supabase, JaCoCo (>80% test coverage).

### 💸 [ZeroDebt](./MobileApp) – Asistente de Gastos Compartidos
- **APK:** [zeroDebt-SC.apk](./MobileApp/zeroDebt-SC.apk)
- **Problema & Solución:** Algoritmo que simplifica deudas grupales en viajes al menor número de transferencias.
- **Stack:** Kotlin, Jetpack Compose, Material 3, MVVM Architecture.

### 🩺 Bravito – Gestión Clínica & Mentoría
- **Web:** [https://bravitoapp.vercel.app/login](https://bravitoapp.vercel.app/login)
- **Problema & Solución:** Plataforma para psicólogos y educadores para centralizar pacientes y turnos.
- **Stack:** Spring Boot, Next.js, PostgreSQL, Firebase Auth, Docker.
